# 🧠 Hybrid CNN-LSTM Image Captioning with Audio Integration

## 📌 Project Overview
This project implements an AI-based system that generates meaningful captions for images and converts them into speech. It combines Computer Vision and Natural Language Processing using a hybrid CNN-LSTM architecture.

---

## 🚀 Features
- Automatic image caption generation  
- Deep learning-based CNN + LSTM model  
- Text-to-speech (audio output)  
- End-to-end pipeline (Image → Caption → Audio)  

---

## 🛠️ Technologies Used
- Python  
- Deep Learning (CNN, LSTM)  
- TensorFlow / Keras  
- NLP  
- Text-to-Speech
